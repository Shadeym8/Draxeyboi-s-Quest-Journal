# Changelog

## [1.1.1] - 2026-05-21

### Fixed
- Background texture opacity corrected.

## [1.1.0] - 2026-05-21

### Added
- **Notes tab** — players can create and manage personal journal entries directly from the quest log. Notes are private (owner-only) and display inline in the detail panel.
- **Tab bar** — Quests and Notes tabs above the two-column layout.
- **Collapsible subpages** — active quests with pages can be collapsed/expanded in the sidebar via a chevron toggle. State survives re-renders.

---

## [1.0.0] - Initial Release

- GM quest creation, status management (active / complete / failed), and page reveal controls.
- Player quest view with inline page content and completion checkboxes.
- Chat card notifications on quest status changes.
